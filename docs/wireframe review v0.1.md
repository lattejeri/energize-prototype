# Wireframe review v0.1
Notes to update html prototype after first pass at producing schematic level wireframe

## Overall feedback
- incredible first pass, great start at starting to include the correct messaging and salient value proposition.
- although i completely understand this is wireframe, the intended styling will be less 'bento' modular and more seamless / flat full bleed sections with minimal whitespace between sections, lots of large format imagery or flat colour blocks do not need to change layout too much for now to factor this in, just beware as we progress
- as a general rule try to not to make stuff up that is not in any of the source docs or in the current website. if you do, please add [speculative] tag after that specualtive content so that i know that is not based on source material. 
- Use sentence case, not title case

## Service detail
- I really like the little value adds you have thought of like the 'download sample report'
- rather than a two column 80 / 20 layout, i think we should aim more for a content block style down the page approach where each beat or concept takes up a full width screen height or half width screen height block and flows into the next.
- LOVE mapping 'why [service] is important for [persona]
- love the process steps - think that shows expertise
- i think the advantages of each service could be used somehow, perhaps as a dedicated content grid with icon for each advantage (may need an 'advantage' taxonomy so we can have a body of icons to apply to an advantage text item)
- the opening paragraph of each service is actually not too bad, it is trying to get to the value behind the service - its just a bit clunky and not tied back to any sort of business objective like reduce risk reduce cost increase revenue / efficiency. i think each service needs a section for the business impact of the service to accompany the 'why' and 'process' content blocks
- love the standards and governance box, just make sure its from source material, if not put a [speculative] tag on it
- the opening sentence Detect latent hot spots, high-resistance joints, and overloaded phases on live switchboards before catastrophic failure or electrical fires occur. Fulfill mandatory commercial property insurance underwriting requirements. is quite good but i think we focus more on the 'fulfill mandatory commercial property insurance underwriting requirements' and then go on with the technical jargon
